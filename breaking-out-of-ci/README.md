# Breaking Out of CI

Slides for "Breaking Out of CI: Container Isolation with Kata Containers" (Hacktober 2026).

## Viewing

Clone or download the repo and open `index.html` in a browser. Everything is local, no internet connection needed.

- Arrow keys (or the arrows in the corner) step through the slides. Most slides reveal one point per step.
- `F` for fullscreen, `Esc` for the overview.

The demo slides show recorded output from our test setup. Project IDs and similar details are replaced with placeholders, and all secrets shown are fake.
